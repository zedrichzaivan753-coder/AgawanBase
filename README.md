# AgawanBase

AgawanBase is a Unity-based game project for the Agawan game concept. This repository contains the project source, scenes, scripts, and supporting assets for the current build.

## Project Overview

- Built in Unity
- Scene-based gameplay structure
- Scripts and assets organized under the standard Unity project folders
- Designed to be opened and developed from the Unity editor

## Getting Started

1. Install Unity Hub and a compatible Unity version for this project.
2. Open the project root folder in Unity.
3. Load the main scene in the Assets/Scenes folder.
4. Press Play in the Unity editor to run the game.

## Project Structure

- Assets/ - game assets, scenes, scripts, prefabs, materials, and settings
- Packages/ - Unity package configuration
- ProjectSettings/ - Unity editor and project settings
- Builds/ - generated build outputs
- AuraTools/ - helper tooling scripts

## Notes

This repository is intended as the working project source for the current game build. Before shipping a release, make sure to test gameplay, verify scene setup, and generate a production build from the Unity editor.
