Note on a build artefact that is easy to misread: Unity also wrote
  Week_13/Abrera_Zedrich_PT5_BackUpThisFolder_ButDontShipItWithYourGame/
(487 files, 525,368,933 bytes) next to the APK. That folder is Unity's IL2CPP build backup -
generated C++ and intermediate assemblies used for debugging a build. It is not part of the
game, it is not installed by the APK, and it was DELETED from the submission folder after the
build completed. Any tool that reported a "686 MB" build was measuring that folder plus the
APK; the artefact that a marker installs is the 38.98 MB APK above.

Why the APK lives under Docs/ and not under Builds/: *.apk is in .gitignore (see
secrets_and_gitignore.txt), so a build under Docs/ is deliberately outside version control
while remaining inside the submission folder. The source that produced it is version
controlled; the binary is the evidence.
