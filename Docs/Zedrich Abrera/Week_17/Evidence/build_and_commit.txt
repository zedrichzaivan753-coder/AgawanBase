## This is the second build of the day, and why

The first 1.0.0-rc1 APK (33,170,243 bytes, MD5 `bb36569a7a1387997c556a56aeaf0344`, 331 s) was built
at 14:17 and was correct at the time. Two defects were found afterwards while capturing the release
screenshots, and both are fixed in this build:

1. **The credits screen printed `0.2`.** Its build line was a string baked into the scene when the
   panel builder last ran, so it kept the version it was built under. It is now filled at runtime from
   `ReleaseInfo.BuildId`, exactly like the version caption on the title, and the screenshot `E3_credits.png`
   shows `AGAWAN BASE  -  1.0.0-rc1  -  built 2026-11-19`.
2. **`productName` was `AgawanBase v1.0.0-rc1`.** Unity derives the PlayerPrefs namespace and the
   `persistentDataPath` folder from the product name, so putting the version in it gave the release
   candidate an empty settings store and a new profile folder: saved match settings and the player
   record of anyone upgrading were silently abandoned. The name is back to `AgawanBase`; the version is
   carried by `bundleVersion`, which is what `Application.version` and every on-screen version label read.

Both are recorded in `issue_disposition.md`. The MD5 above, not the earlier one, is the identity of the
release candidate that `readiness_results.md` describes.

## Package contents check (the DEF-15-04 guard)

`tar -tf Builds/Week17/AgawanBase_RC.apk` lists `classes.dex`, `AndroidManifest.xml` and
`resources.arsc` **at the root of the archive**. That is what separates a real APK from the Week 14
file that was an Android App Bundle wearing an `.apk` filename: an app bundle keeps `classes.dex`
inside `base/dex/`, and no handset will install one. Build App Bundle is off in the project, and the
listing above is the proof for this build.

## Why this APK is smaller than the Week 16 one

Week 16 shipped a **development** build at 68.30 MB. This is a **release** build at 31.63 MB. The
difference is the development player's debug symbols and the extra runtime checks that a release
build strips out; nothing was removed from the game. No size reduction is claimed as an optimisation.
