## Severity scale

Every finding from this session gets exactly one of these, so the fix list in PT6 is ordered by
something other than memory.

| Code | Name | Means | What happens to it |
|---|---|---|---|
| **S1** | Blocker | The task could not be completed at all, even with help. | Fixed before the next build. |
| **S2** | Major | Completed only after help, or after a wrong action that had to be undone (started the wrong match, pressed the wrong button, could not find the screen). | Fixed before the next build. |
| **S3** | Minor | Completed unaided, but with visible hesitation, a misread, or a complaint ("what is this", "why did that happen"). | Fixed if cheap, otherwise scheduled with a week. |
| **S4** | Cosmetic | Noticed only when I asked about it; no effect on the task. | Scheduled, may be deferred. |

A finding is **not** S4 because it is easy to fix. It is S4 only because the tester did not notice
it while playing.
