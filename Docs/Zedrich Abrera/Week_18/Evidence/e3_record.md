## What this file is

E3 is sat **under the approved examination conditions**, on material the examiner selects. It has
not been sat at the time of writing. This is therefore a **record with unfilled fields**, prepared
in advance so that the sitting can be documented immediately afterwards.

It is deliberately not a script. The module counts *"reading an AI-generated defense response"* as a
common mistake, and the Week 18 laboratory purpose requires the student to explain the code and
decisions independently. Nothing in this file answers an examination question. `defense_prep.md`
holds pointers to where the answers live in the repository, because the module also asks the student
to name *specific files, classes, commits, test records, and profiling evidence* — knowing where
those are is preparation, not substitution.
