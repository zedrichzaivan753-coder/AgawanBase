=== FINAL STATE AFTER STEP 6 ===
Captured: 2026-11-19, after the PA2 commit and the v1.0.0-pa2 tag

The PA2 submission commit is the commit that contains this file: it is the tip of main, its
subject is "Week 18: PA2 final demonstration package and individual defense", and it carries
the annotated tag v1.0.0-pa2. The commit and the tag therefore name the same object, and both
ids are read from the repository rather than written down here:

  git rev-parse HEAD                      -> the PA2 commit id
  git rev-parse v1.0.0-pa2^{}             -> the same id (the tag's target)
  git describe --tags --exact-match HEAD  -> v1.0.0-pa2
  git cat-file -t v1.0.0-pa2              -> tag   (annotated, not lightweight)

The id is deliberately not written into this file. Writing it here would change the tree,
which changes the id, which makes the number wrong the moment it is committed. The four
commands above are the authoritative read, and they cannot go stale.
