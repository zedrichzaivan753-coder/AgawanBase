DEF-15-04, found while producing this build
-------------------------------------------
The first build of this deliverable reported Success and wrote a 50,097,152-byte file
named .apk. It was not an APK. The editor's Build App Bundle flag was on, so Unity ran
Gradle's "bundleDebug" task and the tool copied launcher-debug.aab to the requested
.apk path. The zip listing proved it: BundleConfig.pb and base/manifest were at the
root, there was no classes.dex.

    wrong artefact  : 50,097,152 bytes, md5 ed3afc1290fd4cf1858d30056df0dfa5
                      (an .aab with an .apk filename, not installable by adb)
    corrected       : 54,489,688 bytes, md5 f4fa8b51d465f2e9120d9d23c7769245
                      (classes.dex + classes2-4.dex + lib/arm64-v8a/*.so, 428 entries)

Verified after the fix by listing the archive, by aapt2 dump badging, and by the fact
that the size grew by exactly the dex and native payload an APK carries and an AAB
stores compressed. The same defect is present in the Week 14 artefact
(Abrera_Zedrich_PT6_Playtest.apk, 50,097,691 bytes, md5 0eef3dcb32fc0b9852bb4627c18d50d4):
it too is an .aab with an .apk name. See defect_log.md, DEF-15-04.
